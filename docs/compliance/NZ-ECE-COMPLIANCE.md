# NZ ECE implementation matrix

Verified 28 August 2026. This matrix records design inputs, not legal advice or a claim that this application or a centre is legally compliant. A licensed service must independently validate its procedures, retention, signature policy and deployment before using live data.

| Topic | Implemented behaviour | Primary official source | Status and limitation |
| --- | --- | --- | --- |
| Sleep monitoring (HS107) | Sleep sessions retain put-down, asleep, wake and get-up times. Check records retain warmth, breathing, wellbeing, staff and time. Server status is green/amber/red; centre interval is constrained to 5–10 minutes. | [Ministry of Education HS107](https://www.education.govt.nz/education-professionals/early-learning/licensing-and-certification/new-licensing-criteria-for-centre-based-ece-services-v1/health-and-safety/hs107-sleep-monitoring) | Implemented data model/API. Each centre must display and implement its own procedure and determine stricter individual needs. |
| Medicine authority and categories (HS122) | The centre-based workflow accepts Category (i) and Category (ii) only. Authority captures medicine, dose, route, schedule and instructions; receipt is separate, so an unreceived medicine is unavailable for administration. | [Ministry of Education HS122](https://www.education.govt.nz/education-professionals/early-learning/licensing-and-certification/new-licensing-criteria-for-centre-based-ece-services-v1/health-and-safety/hs122-medicine-administration), [medicine categories](https://www.education.govt.nz/education-professionals/early-learning/running-ece-centre/licensing-criteria-for-kohanga-reo/appendix-3-categories-of-medicine-for-criterion-hs28) | API validation corrected to the current centre-based category model. Parent signature UI and authority revision UI remain a next-phase item. |
| Medicine administration | Administration records child, medicine authority, dose, actual time, staff and outcome; an active receipt and a staff PIN are required. The PIN is transient and is never stored in records, audit data or the offline outbox. | [Ministry of Education HS122](https://www.education.govt.nz/education-professionals/early-learning/licensing-and-certification/new-licensing-criteria-for-centre-based-ece-services-v1/health-and-safety/hs122-medicine-administration) | API implemented. Offline medication remains a local draft/pending-verification workflow rather than a false finalisation. |
| Accidents, injury and illness | Structured incident drafts retain location, environment, type, body-area identifiers and time-stamped actions. Finalisation requires staff PIN; parent event wording never identifies another child. | [Education (Early Childhood Services) Regulations 2008](https://www.legislation.govt.nz/regulation/public/2008/0204/latest/DLM1412594.html) | Structured API implemented. Parent notification and signature/revision UI are still required before a live trial. |
| Attendance and operational records | Actual arrival/departure and room visit history are separate from enrolment room. Effective time and creation time are both retained. | [Education (Early Childhood Services) Regulations 2008](https://www.legislation.govt.nz/regulation/public/2008/0204/latest/DLM1412594.html) | Implemented as an operational record, not an enrolment-system replacement. |
| Privacy and family access | Server-side centre and parent-child checks, explicit parent/staff visibility, HttpOnly sessions and exported-data filtering prevent a parent from using an ID to reach another child or private staff notes. | [Health Information Privacy Code 2020](https://www.privacy.org.nz/privacy-principles/codes-of-practice/hipc2020/), [children's privacy guidance](https://www.privacy.org.nz/resources-and-learning/a-z-topics/protecting-children-and-young-peoples-privacy/childrens-privacy-guidance-for-the-education-sector/chapter-4-privacy-and-confidentiality/) | Technical controls implemented; the operator remains responsible for access requests, retention, breach response and policies. |
| Digital records/signatures | Signature table binds signer metadata, purpose and exact domain revision. | [Education regulations: management and records](https://www.legislation.govt.nz/regulation/public/2008/0204/latest/DLM1412594.html) | Database foundation exists; touchscreen signature collection/revision workflow is not yet exposed in the UI. |

The Ministry pages above state the current sleep check expectation as every 5–10 minutes, including warmth, breathing and general wellbeing, and medicine records as including the child, medicine/amount, date/time, administrator and required acknowledgement. Recheck these sources and current licensing criteria before a production release.
